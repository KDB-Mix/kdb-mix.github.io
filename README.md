# My website

This is my own websites, I put all my projects here with some more things. Enjoy :)
___
If you want to edit it, make sure that you have git installed, and run this in the 'git cmd' app or the terminal:
```git clone https://github.com/KDB-Mix/kdb-mix.github.io```

You will have a folder named `kdb-mix.github.io` in the place where you ran the command from (default in windows is C:/Users/your-username)

Then make sure that you have npm installed and correctly setup

To run the page on your machine, in the terminal, go to the repo folder
```cd kdb-mix.github.io```
and run
```npm run dev```

To build it, go to that same folder in the terminal and run
```npm run build```
